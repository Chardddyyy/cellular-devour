# cellular-devour

A real-time multiplayer cell-devouring arena game built with Node.js, Express, WebSockets, and HTML5 Canvas.

## Features
- Real-time multiplayer synchronization via WebSockets
- Fluid cell movement with mouse tracking
- Pellet spawning & consumption
- Player vs. player devouring mechanics (eat smaller cells to grow)
- Spacebar split/dash mechanic
- Live leaderboard & player count

## Getting Started

### Prerequisites
- Node.js installed

### Installation
```bash
npm install
```

### Run Server
```bash
npm start
```
Open `http://localhost:3000` in your browser.
